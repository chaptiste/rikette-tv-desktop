# OBS runtime

Generated by `pnpm --filter desktop obs-runtime` (Windows). Holds the parts of OBS Studio that
Rikette uses, in OBS's own layout, and is bundled into the installer as `obs/`:

- `bin/64bit/`: `obs.dll` and its dependencies, the FFmpeg DLLs, `ffmpeg.exe` and `ffprobe.exe`
  (from the obs-deps build OBS itself uses), and `rikette-capture.exe`.
- `obs-plugins/64bit/`: game, window and display capture, WASAPI audio, and the encoders.
- `data/`: the shaders and plugin data those need, including the game capture hook.

Everything else in OBS (Qt, the browser source, streaming, websocket, filters) is left out.
Only this README is committed.
